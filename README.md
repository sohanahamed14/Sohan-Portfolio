# Sohan Ahammed — Cinematic Scrollytelling Portfolio

A modern, high-performance developer portfolio featuring a 199-frame HD scroll animation canvas, pure liquid glass aesthetics, and a responsive two-wing layout.

## 🛠️ Tech Stack
- **Core**: Vanilla HTML5, CSS3, JavaScript (ES Modules)
- **Database**: Supabase
- **Styling**: Pure Liquid Glass System (Backdrop Blur, SVG Refraction, Specular Bevel Highlights)
- **Animation**: Custom High-Performance Canvas Lerp Interpolation
- **Bundler / Dev Server**: Vite

---

## 💻 Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
